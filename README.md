# ᚱ RuneCaster

A digital divination tool for casting Elder Futhark runes using haptic feedback and randomized orientation logic.

## Features
- **Shake to Cast:** Uses accelerometer data to "throw" stones.
- **Merkstave Logic:** Supports reversed meanings based on landing orientation.
- **Journal:** Save your readings to a local database.

## Installation
1. Clone the repo: `git clone https://github.com/username/rune-caster.git`
2. Install dependencies: `npm install`
3. Run the app: `npx expo start`
